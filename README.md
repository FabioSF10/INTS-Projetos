# 🏥 INTS - Ecossistema de Automação e Infraestrutura

Este repositório centraliza as soluções, scripts e ferramentas desenvolvidas para otimizar a operação de TI no **Hospital INTS**. O foco principal é a automação de tarefas repetitivas, redução de custos operacionais (FinOps local) e melhoria da experiência do usuário final.

---

## 🚀 Projetos Ativos

### 🌿 [ECONOMIA DE ENERGIA](./ECONOMIA_ENERGIA)
**Objetivo:** Redução do consumo de energia elétrica em notebooks e desktops.
* **Tecnologias:** Batch Script, PsTools (Sysinternals), Protocolo RPC.
* **Status:** ✅ Validado / Em Produção.
* **Diferencial:** Implementação de aviso prévio ao usuário (msg.exe) antes da suspensão do hardware.
