# 🏥 INTS - Ecossistema de Automação e Infraestrutura

Este repositório centraliza as soluções, scripts e ferramentas desenvolvidas para otimizar a operação de TI no **Hospital INTS**. O foco principal é a automação de tarefas repetitivas, redução de custos operacionais (FinOps local) e melhoria da experiência do usuário final.

---

## 🚀 Projetos Ativos

### 🌿 [WinSleep-Automator](./WinSleep-Automator)
**Objetivo:** Redução do consumo de energia elétrica em notebooks e desktops.
* **Tecnologias:** Batch Script, PsTools (Sysinternals), Protocolo RPC.
* **Status:** ✅ Validado / Em Produção.
* **Diferencial:** Implementação de aviso prévio ao usuário (msg.exe) antes da suspensão do hardware.

---

## 🧠 Visão Geral Técnica

Como estou em transição para a trilha de **Cloud Computing (AWS)**, aplico conceitos de infraestrutura escalável mesmo em ambientes On-Premise (locais):
- **Automação via Scripting:** Eliminação de processos manuais "máquina por máquina".
- **Gestão de Inventário:** Uso de listas dinâmicas (`pcs.txt`) para controle de frota.
- **Segurança de Credenciais:** Scripts estruturados para não expor senhas em ambientes de versionamento.

---

## 🛠️ Ferramentas Utilizadas nos Projetos
- **Linguagens:** Windows Batch, PowerShell.
- **Utilitários:** Microsoft Sysinternals (PsExec, PsShutdown).
- **Ambiente:** Redes baseadas em Active Directory (AD).
